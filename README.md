# GitHub achievements tracker

Personal public repo for [EthanSharma-Wadeson](https://github.com/EthanSharma-Wadeson), used to earn the GitHub profile achievements that can be completed from a single account.

GitHub achievements are a [public preview](https://docs.github.com/en/account-and-profile/reference/profile-reference). They can take hours to appear, and GitHub may change the rules.

## What this repo does not do

It does not farm gold tiers (hundreds of empty pull requests), use extra accounts, or impersonate other users as co-authors. Those patterns can get accounts restricted.

See [docs/achievements.md](docs/achievements.md) for the unlock criteria this tracker uses.
