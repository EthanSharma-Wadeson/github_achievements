# Achievement criteria

Community-reported thresholds. GitHub does not publish a complete official catalog.

## Obtainable from this account

- **Quickdraw** — Close an issue or pull request within 5 minutes of opening it.
- **YOLO** — Merge a pull request that has no reviews.
- **Pull Shark** — Merge at least 2 pull requests. Reported tiers: 2 / 16 / 128 / 1024.

## Obtainable, but not from this repo alone

- **Pair Extraordinaire** — A merged pull request whose commit includes a `Co-authored-by` trailer for another GitHub user. Reported tiers: 1 / 10 / 24 / 48.
- **Galaxy Brain** — 2 answers marked as accepted by someone else in a public repository's Q&A discussions. Self-answers do not count. Reported tiers: 2 / 8 / 16 / 32.
- **Starstruck** — 16 stars on a repository you own. Reported tiers: 16 / 128 / 512 / 4096.
- **Public Sponsor** — Publicly sponsor a user or org through GitHub Sponsors.

## Unavailable

- **Heart On Your Sleeve** and **Open Sourcerer** were experimental and are not currently awarded.
- **Arctic Code Vault Contributor** required a contribution archived in the February 2020 snapshot.
- **Mars 2020 Helicopter Contributor** required a commit in a NASA JPL-listed repository for that mission.
